# AI File Scanner — Iteration 2 Changelog

This log continues the history of the AI File Scanner project. Iteration 1 is documented in the repository’s top-level `CHANGELOG.md`.

## 2026-10-12 — Review form and Flask receiver

### Added

- Customer name, purchased product, and review fields.
- Required-field checks and small green checkmark feedback as fields are completed.
- A white, notebook-inspired page with hand-drawn background lines and a hand-drawn form border.
- A Flask route that serves the HTML template and stylesheet.
- A form submission route that reads all three answers, prints them in the Flask terminal, and returns a confirmation.

### Current status

- This iteration is a data-collection learning step for the AI File Scanner project.
- Form answers are not saved to a file or Google Sheet yet; Google Sheets integration is still to come.
- The form design may continue to change as the project develops.
