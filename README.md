# AI File Scanner
An early front-end prototype for a document-scanning application.

## Current version

This prototype contains a simple navigation bar with “New Upload” and “Existing Upload” options. Selecting an option changes which one appears active.

File uploading, document scanning, and a backend are not implemented yet.

## Project files

- `document_scanner_ui.html` — page structure and navigation behavior
- `document_scanner_ui.css` — navigation styling

## Run locally

Open `document_scanner_ui.html` in a web browser.

## Status

This is version 1 of an ongoing project. Features and documentation will be updated as development continues.
